# Guide de l'admin — créer un site client en 30 minutes

Aucune compétence technique nécessaire. Tout se passe dans le Studio : `https://studio.flowtechnologie.ma`.

## 1. Préparer (avant de commencer)
Demander au client : son logo (PNG/SVG), 5 à 10 photos **dont il détient les droits**, ses coordonnées (téléphone, WhatsApp, email, adresse), sa liste de produits/services (nom + 1 phrase + photo), ses réseaux sociaux, éventuellement une vidéo (lien YouTube ou fichier mp4).

## 2. Créer le site (5 min)
**Sites → Nouveau site**
1. **Modèle** : choisir le plus proche de l'activité (Distributeur / Services / Commerce-Restaurant / Santé / Page blanche).
2. **Identité** : nom, slogan, couleurs (prendre celles du logo), téléphone, email, adresse, domaine si connu.
3. **Accès** : email + mot de passe du client (il pourra gérer son contenu lui-même).
4. **Créer le site** → le site est prêt avec des pages pré-remplies.

## 3. Personnaliser (20 min)
Dans le menu du site :
- **Paramètres** : logo, favicon, WhatsApp, réseaux sociaux, carte Google Maps (Google Maps → Partager → Intégrer → copier l'adresse `src`), texte du pied de page, police, arrondis, style d'en-tête.
- **Médias** : glisser-déposer les photos du client.
- **Produits** : créer les catégories, puis les produits (image, résumé, description, caractéristiques, PDF). Cocher *Mis en avant* pour ceux à afficher sur l'accueil.
- **Actualités & salons** : salons à venir (date, lieu, image, lien), actualités.
- **Pages → Accueil → Modifier** : cliquer sur chaque bloc à gauche, modifier les textes à droite, **Enregistrer** (ou Ctrl+S). Ajouter / dupliquer / supprimer / réordonner les blocs avec les flèches. L'aperçu en bas se met à jour après enregistrement.
- Créer d'autres pages si besoin (Pages → Nouvelle page).

Vérifier avec **Voir le site** : sur ordinateur **et** sur téléphone.

## 4. Mettre en ligne
Suivre **Mise en ligne** (5 étapes vérifiées automatiquement) — détails dans `PROCEDURE-DEPLOIEMENT.md` §C.

## 5. Livrer
Envoyer au client :
- l'adresse de son site ;
- son accès admin : `https://son-domaine/admin` + email + mot de passe ;
- ce qu'il peut faire seul : produits, actualités, photos, textes des pages, coordonnées, messages reçus.

## Les blocs disponibles
Bannière d'accueil (image ou vidéo) · Points forts · Texte + image · Texte libre · Galerie défilante · Produits / services · Actualités / salons · Chiffres clés · Appel à l'action · Vidéo · Questions fréquentes · Équipe / partenaires · Formulaire de contact · Espace.

## Mise en forme des textes longs
Dans les champs « Contenu », « Description », « Texte complet » :
`# Titre`, `## Sous-titre`, `- élément de liste`, `**gras**`, `*italique*`, `[texte du lien](https://…)`. Une ligne vide = nouveau paragraphe.

## Règles
- Jamais de photos ou de textes copiés depuis un autre site (droits d'auteur). Visuels fournis par le client ou libres de droits.
- Un domaine = un site. Le Studio refuse un domaine déjà utilisé.
- Le compte *Client* ne voit que son site et ne peut ni changer le domaine ni publier.
